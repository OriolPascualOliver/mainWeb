¿Qué incluye un MVP?

  • Diseño electrónico y una PCB funcional.
  • Firmware y, si hace falta, una app o dashboard básicos.
  • Envolvente impresa o mecanizada.
  • Un pequeño lote de unidades funcionales para pruebas con usuarios.
  • Documentación de diseño lista para la siguiente fase.

¿De quién es la propiedad intelectual?

Tú decides. Si quieres la propiedad completa, se te transfieren todos los archivos de diseño y el código fuente. El NDA es estándar.

¿Y si cambian las especificaciones?

Los cambios pasan por un proceso de solicitud de cambio acordado, para que alcance, plazo y coste estén siempre claros.
