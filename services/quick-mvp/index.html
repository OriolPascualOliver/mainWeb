What is included in an MVP?

  • Electronics design and a working PCB.
  • Firmware, plus a basic app or dashboard when needed.
  • Printed or machined enclosure.
  • A small set of working units for user testing.
  • Design documentation ready for the next phase.

Who owns the IP?

You decide. If you want full ownership, all design files and source code are transferred to you. NDAs are standard.

What if the specifications change?

Changes go through an agreed change-request process, so scope, time and cost stay explicit.
